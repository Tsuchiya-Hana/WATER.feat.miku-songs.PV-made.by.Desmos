# 任务3：缓动的重要性与 32 种曲线

## 为什么缓动不可省

缓动曲线规定动画在时间中的速度变化。线性插值从开始到结束保持同一速度，适合恒速运动，却容易让入场、转向、落点和退场显得机械。缓动能让动作有加速、减速、惯性、冲击或回弹，使图形像是被推动、吸引、碰撞或释放；多个元素使用不同曲线与错开的时间，才能形成有层次的 MG 动势。

单次动画和序列动画都应明确选择缓动。序列中的每个转折都可能是一次新的加速或停顿，不能因为前一段已经缓动，就让后续段落默认线性。常量阶梯只用于故意逐帧跳变、计数或切字等离散动作；线性只用于确实需要恒速的循环或匀速运动。它们是特殊风格工具，不是省事的默认值。

## `f_l` 的 32 个编号

函数库将缓动编号写在 `f_l` 中。下表按代码中的索引顺序列出；“入”表示慢起快收，“出”表示快起慢收，“入出”表示两端慢、中段快。

| 编号 | 曲线 | 运动感觉与适用情形 |
|---|---|---|
| 1 | Linear 线性 | 恒速直行；仅在需要匀速感时使用，不作为单次动作默认。 |
| 2 | Constant 阶梯常量 | 逐步跳值；适合计数、逐字切换、硬切等离散变化。 |
| 3 | Sine In | 正弦入；轻柔起步，适合缓慢启动或微小漂移。 |
| 4 | Sine Out | 正弦出；自然刹停，适合落位、淡出式位移。 |
| 5 | Sine InOut | 正弦入出；平滑往返，适合柔和的镜头内运动。 |
| 6 | Quad In | 二次入；比正弦更明确的加速，适合短促启动。 |
| 7 | Quad Out | 二次出；有力起步后收住，适合元素弹入构图。 |
| 8 | Quad InOut | 二次入出；平衡、清晰，适合常规位移。 |
| 9 | Cubic In | 三次入；前段更沉，适合蓄力后冲出。 |
| 10 | Cubic Out | 三次出；冲入后快速稳住，适合重物落点。 |
| 11 | Cubic InOut | 三次入出；对比鲜明，适合镜头或主体的大幅运动。 |
| 12 | Quart In | 四次入；起步克制、后段明显加速，适合下坠或被吸入。 |
| 13 | Quart Out | 四次出；急促进入、强力刹停，适合强调性落位。 |
| 14 | Quart InOut | 四次入出；中段冲劲强，适合有重量的镜头转换。 |
| 15 | Quint In | 五次入；非常缓的蓄力后高速加速，适合积累张力。 |
| 16 | Quint Out | 五次出；强冲后迅速锁定，适合重击后的定格。 |
| 17 | Quint InOut | 五次入出；两端停顿明显，适合大幅度戏剧性运动。 |
| 18 | Expo In | 指数入；近乎静止后爆发，适合突然加速的冲刺。 |
| 19 | Expo Out | 指数出；快速冲入后细致贴合，适合精准吸附或聚焦。 |
| 20 | Expo InOut | 指数入出；强烈的加速和制动，适合段落级转场。 |
| 21 | Circ In | 圆弧入；沿圆弧关系逐渐加速，适合绕行或转向。 |
| 22 | Circ Out | 圆弧出；弧线式减速，适合旋转停靠。 |
| 23 | Circ InOut | 圆弧入出；连续、柔韧，适合轨道或波形运动。 |
| 24 | Back In | 回拉入；先反向蓄势再前进，适合有预备动作的弹射。 |
| 25 | Back Out | 回拉出；越过终点再回收，适合弹性落位。 |
| 26 | Back InOut | 回拉入出；两端都有反向张力，适合夸张的转场。 |
| 27 | Elastic In | 弹性入；带振荡地加速进入，适合被吸入或能量聚集。 |
| 28 | Elastic Out | 弹性出；过冲后振荡收敛，适合弹簧、气泡或抖动落点。 |
| 29 | Elastic InOut | 弹性入出；全程有振荡，适合少量、强烈的戏剧性动作。 |
| 30 | Bounce In | 弹跳入；以反弹方式启动，适合球体或撞击后的入场。 |
| 31 | Bounce Out | 弹跳出；多次碰撞后停稳，适合落地、撞壁和弹球。 |
| 32 | Bounce InOut | 弹跳入出；入场和退场都带反弹，适合卡通化的短动作。 |

`Back` 会越过端点，`Elastic` 与 `Bounce` 会振荡或反弹；这些曲线应配合合适的距离、时长和视觉对象，避免重要字幕在振荡中难以阅读。正弦、幂次和圆弧曲线通常更适合细腻位移；指数、Back、Elastic、Bounce 更适合有明确冲击或材质感的动作。

## 如何选择并督促自己使用

1. 先写动作意图，再选曲线：缓慢启程选入曲线，快速到位选出曲线，平稳穿越选入出曲线；撞击、弹簧和回弹才选 Back、Elastic 或 Bounce。
2. 为每个 `m()` 单次动画填写明确的 `way`；为 `m_2()` 中的每个片段逐段检查缓动编号。除非要恒速或阶梯效果，不把 1、2 当作常规选项。
3. 把字幕也纳入动作设计：入场、关键字强调、换行和退场分别考虑时间、位移、缩放或遮罩，不让字幕只静止停留。
4. 对照时间曲线和画面逐镜检查。每秒可有约 3–10 个并行动作，但要分配主次、错开起点，避免所有元素同一时刻同一种曲线运动。
5. 自检时列出镜头中的单次/序列动作，逐项标注曲线编号及理由；发现无理由的线性动作就重新判断。播放检查要覆盖入场、转折、结束帧和字幕可读性，而不是只看静态截图。

大量使用缓动不是把所有对象都做成弹簧，而是有意识地给每一个动作安排速度变化，并用曲线差异塑造节奏、重量和情绪。
